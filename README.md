# 🍁 大雪山三天兩夜・秋日慢活小旅行

一份可直接在瀏覽器開啟、可自由編輯的**互動式旅遊手冊**。
這次不趕路、不挑戰極限，只在最美的季節，用最舒服的步調走進金黃與楓紅交織的大雪山。

> 單一 `index.html` 檔案，無需安裝、無需後端伺服器，所有修改自動儲存在你的瀏覽器中。

## ✨ 功能特色

### 📋 行程總覽
- **出發倒數計時**：即時顯示距離出發的天、時、分、秒，可自訂出發時間
- **行前叮嚀**：秋日添衣、油箱加滿、提防濃霧等注意事項，可新增 / 編輯 / 刪除
- **行李打包清單**：勾選已準備的物品，進度一目了然

### 🗺️ 每日行程
- 依天數分頁，時間軸呈現每個行程
- 分類標籤：美食餐飲、森林步道、自然景觀、住宿休整、交通移動、漫活筆記
- 每個行程一鍵開啟 **Google Maps 導航**
- 新增、編輯、刪除、上下移動排序行程；可新增或刪除天數

### 💰 預算管理
- 設定總預算，自動計算已付 / 預估 / 剩餘金額
- 依分類（住宿、餐飲、門票、交通…）統計支出分佈
- 每筆費用可標記「已付款」或「預估」，並對應到特定天數

### 💾 資料保存與分享
- **自動儲存**：所有修改即時存入瀏覽器 `localStorage`，重新整理不會遺失
- **匯出完整 HTML**：將目前所有內容打包成一個新的 `.html` 檔，可直接傳給旅伴開啟
- **匯出 / 匯入 JSON**：備份或還原行程資料
- **重設**：一鍵恢復為預設行程

## 🚀 使用方式

### 方法一：直接開啟
下載 `index.html`，用瀏覽器（Chrome、Edge、Safari 等）開啟即可。

### 方法二：GitHub Pages 線上瀏覽
1. 進入 repo 的 **Settings → Pages**
2. Source 選擇 `Deploy from a branch`，分支選 `main`、資料夾選 `/ (root)`
3. 儲存後即可透過 `https://itmckira.github.io/Slow-Paced-Nature_Trip/` 瀏覽

> 💡 資料儲存在各自的瀏覽器中，彼此不會同步。若要和旅伴共享最新版本，請使用「匯出完整 HTML」或「匯出 JSON」功能。

## 🛠️ 技術說明

| 項目 | 使用技術 |
| --- | --- |
| 架構 | 單一 HTML 檔（HTML + CSS + 原生 JavaScript） |
| 樣式 | [Tailwind CSS](https://tailwindcss.com/)（CDN） |
| 圖示 | [Font Awesome 6](https://fontawesome.com/)（CDN） |
| 字型 | Google Fonts：Noto Sans TC / Noto Serif TC |
| 資料儲存 | 瀏覽器 `localStorage`（key：`snow_mountain_trip_data`） |

> 需連網以載入 Tailwind、Font Awesome 與字型；離線時功能仍可運作，但樣式可能不完整。

### 自訂預設行程
預設資料定義在 `index.html` 中的 `DEFAULT_TRIP_DATA` 物件，包含：
`title`、`groupName`、`departureTime`、`slogan`、`totalBudget`、`expenses`、`notices`、`packingList`、`days`。
修改此物件即可改造成其他旅程的手冊。
